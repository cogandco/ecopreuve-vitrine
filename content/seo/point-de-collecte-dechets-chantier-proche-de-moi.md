Un seul outil couvre la quasi-totalité des flux déjà vus dans cette famille : OCA Bâtiment, la cartographie officielle des éco-organismes agréés PMCB. Une exception notable existe cependant, le verre plat de chantier, qui suit un circuit à part avec son propre outil. Voici lequel utiliser selon ce que vous avez à évacuer.

## Ce que dit la règle

OCA Bâtiment (oca-batiment.org) est le localisateur de référence pour la quasi-totalité des flux REP PMCB déjà couverts dans cette famille : inertes, métal, bois, plâtre, plastique. Cet outil est géré directement par les éco-organismes agréés (Ecominéro, Valobat, Ecomaison, Valdelia) : ce n'est pas un site tiers, c'est la cartographie officielle de la filière elle-même.

Conseil pratique pour bien l'utiliser : précisez le type de déchet exact dans la recherche, pas "gravats" ou "déchets de chantier" en général, mais le matériau précis, béton, plâtre, bois, plastique, ainsi qu'un volume approximatif. Ça affine les résultats vers les points qui acceptent réellement ce que vous avez à déposer, plutôt que vers une liste générique.

## Le modèle

Selon ce que vous avez à évacuer, l'outil à utiliser change :

- **OCA Bâtiment** (oca-batiment.org) : pour les flux minéraux, le bois, le métal, le plâtre, le plastique. C'est le point d'entrée par défaut pour la plupart des cas déjà vus dans cette famille.
- **Federec, via recyclageverreplat.com** : spécifiquement pour le verre plat de chantier, déjà détaillé sur [la page dédiée au verre](/tri-dechets-chantier-verre-point-de-collecte). Un point de vigilance technique à connaître avant d'y aller : ce site fonctionne en HTTP, sans connexion sécurisée. Mieux vaut taper l'adresse directement dans la barre du navigateur plutôt que suivre un lien copié ailleurs.
- **BatiDéchets** (batidechets.ffbatiment.fr), l'outil de la FFB : une ressource complémentaire, en particulier pour le bois. Il ne remplace pas OCA Bâtiment, il fonctionne différemment : plutôt qu'une carte de points, c'est un outil d'orientation qui identifie la solution adaptée à un déchet donné.

Ces trois outils sont ouverts aux particuliers comme aux professionnels, sans distinction d'accès au niveau de l'outil lui-même. La distinction se joue ensuite point par point : chaque point de collecte affiche le type de public qu'il accepte.

## Le problème du fait main

Le réflexe le plus courant : taper une recherche du type "point de collecte déchets de chantier", sans préciser le flux. Résultat, une liste de résultats généraux, pas toujours pertinents, ou un renvoi vers le mauvais outil pour ce que vous avez réellement à évacuer. Préciser le matériau dès la recherche, béton plutôt que gravats, plâtre plutôt que déchets de plâtrerie, change directement la pertinence du résultat obtenu.
