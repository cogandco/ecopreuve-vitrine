Toutes vos chutes de bois ne vont pas dans la même benne : la réglementation distingue trois classes selon le degré de traitement. Le point le plus spécifique à votre métier ne concerne d'ailleurs pas le bois lui-même, mais la peinture qui le recouvre parfois sur les menuiseries anciennes. Voici ce que dit le texte sur ces deux sujets.

## Ce que dit la règle

Le bois de chantier se classe en trois catégories.

La **classe A** regroupe le bois brut, non traité chimiquement : palettes non colorées, planches de bois massif, bois de calage.

La **classe B** regroupe le bois faiblement traité : peint, verni, contreplaqués, panneaux avec colles, charpentes et planchers traités.

La **classe C** regroupe le bois fortement imprégné, classé déchet dangereux (code 17 02 04*) : bois traité à la créosote ou aux sels métalliques type CCA. Cette classe reste rare pour un menuisier standard, elle concerne surtout des usages d'infrastructure extérieure, traverses de chemin de fer, poteaux, piquets de vigne, plutôt que les ouvrages de menuiserie courants.

## Le modèle

Le point le plus spécifique à ce métier ne concerne pas le bois lui-même, mais ce qui le recouvre. Dans les bâtiments construits avant 1949, année où l'usage du plomb dans les peintures a été interdit pour les professionnels (la commercialisation elle-même n'a été totalement interdite qu'en 1993), les fenêtres, portes et boiseries anciennes peuvent être recouvertes de peinture au plomb. Les déchets issus de leur dépose, poussières, débris, chutes de bois peint, doivent être collectés dans des contenants étanches, sacs scellés ou big bags, et envoyés vers une filière spécialisée, pas vers la benne bois classique.

Autre piège à connaître : mélanger du bois classe A et du bois classe B dans la même benne reclasse l'ensemble du lot en classe B. Ce n'est pas une catastrophe, le B reste valorisable, mais ça dévalue un lot qui aurait pu rester en classe A s'il avait été trié séparément.

Sur la valorisation : le bois classe A, et le bois classe B sous conditions, peuvent être utilisés en chaufferie biomasse une fois broyés. Pour la classe B, cette valorisation suppose un traitement de fumée adapté, pour éviter le rejet de substances issues des peintures ou vernis présents en faible dose dans le bois.

## Le problème du fait main

Le réflexe le plus courant : tout mettre dans la même benne bois, sans distinguer les classes, faute de temps ou de réflexe de tri. Sur un chantier de rénovation, l'autre oubli fréquent, c'est de déposer de vieilles menuiseries sans se poser la question de l'âge du bâtiment, alors que ce point conditionne directement si la peinture qui les recouvre doit partir vers une filière spécialisée ou non.
